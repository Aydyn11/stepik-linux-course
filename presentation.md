## Слайд 1: Что такое Linux?

- **Linux** — семейство Unix-подобных операционных систем
- Ядро Linux + системные утилиты GNU
- **Особенности:**
  - Бесплатное распространение
  - Открытый исходный код
  - Высокая стабильность и безопасность
  - Широкое применение: от серверов до встраиваемых систем

## Слайд 2: Основы командной строки

| Команда | Действие | Пример |
|---------|----------|--------|
| `pwd` | Показать текущую папку | `/home/user` |
| `ls` | Список файлов | `ls -la` (все файлы подробно) |
| `cd` | Сменить директорию | `cd /home`, `cd ..` |
| `mkdir` | Создать папку | `mkdir new_folder` |
| `rm` | Удалить файл/папку | `rm -r folder` |

## Слайд 3: Файловая система Linux

- **Иерархическая структура** — всё начинается с корня `/`
- **Важные каталоги:**

| Каталог | Назначение |
|---------|------------|
| `/home` | Домашние папки пользователей |
| `/etc` | Конфигурационные файлы |
| `/var` | Переменные данные (логи) |
| `/tmp` | Временные файлы |
| `/usr` | Пользовательские программы |

## Слайд 4: Права доступа

- **Три типа прав:**
  - `r` (read) — чтение
  - `w` (write) — запись
  - `x` (execute) — выполнение

- **Три категории пользователей:**
  - Владелец (owner)
  - Группа (group)
  - Остальные (others)

- **Пример:** `chmod 755 file.sh`
  - `7` = rwx для владельца
  - `5` = r-x для группы
  - `5` = r-x для остальных

## Слайд 5: Текстовые редакторы

### nano (простой для новичков)
- `nano file.txt` — открыть/создать
- `Ctrl+O` — сохранить
- `Ctrl+X` — выйти

### vim (мощный, требует изучения)
- `vim file.txt` — открыть
- `i` — режим вставки
- `Esc` — выйти из режима вставки
- `:w` — сохранить
- `:q` — выйти
- `:q!` — выйти без сохранения
